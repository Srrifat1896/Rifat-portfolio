# Md. Saif Al Mahmud Rifat — Portfolio

A responsive personal portfolio built with plain HTML, CSS, and JavaScript. It includes profile and skills sections, education and coursework, academic and personal projects, interests, certification, and contact details.

## Run locally

Open `index.html` in a browser, or serve this folder with any static file server. No package installation or build step is required.

## Update content and images

- Edit `data.js` to update profile information, skills, coursework, projects, interests, certification, and contact details.
- Keep the portrait and project cover images in `assets/images/` and preserve their filenames referenced by `data.js`.
- `styles.css` contains the responsive layouts, light and dark themes, and motion styling. `script.js` handles rendering and interactions.

## Publish

This is a static site. For Netlify, set the repository root as the publish directory and leave the build command empty.
