# Rifat's Portfolio

A responsive personal portfolio built with plain HTML, CSS, and JavaScript.

## Run locally

Open `index.html` in a browser, or serve this folder with any static file server.

## Update content

Edit `data.js` to update profile information, skills, coursework, project details, and contact links. Keep the image files in `assets/images/` so the portrait and project covers continue to load.

## Deploy

This is a static site. For Netlify, use the repository root as the publish directory; no build command is required.
